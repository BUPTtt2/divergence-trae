# 04 · 前端关键模块

> 前端入口：`src/main.jsx` → `src/App.jsx`（路由 + Provider + ErrorBoundary + lazy 分包）。

## 1. 页面层 `src/pages/`

### Game.jsx（最核心，最大）
- 推演台 `/sandbox`。持有 `useGameFlow()` 返回的全部状态与 handler。
- 负责渲染：3D Board、顶部 ProcessStepper、左上角阶段卡片、右下角导航条、仪式卡片（P1-P4 + 三变）、命牌面板、Agent 对话浮层、ChoiceHud 等。
- 内含大量内联组件：`GuaMirror`（赛博八卦盘 SVG）、`DynamicBagua`（左下角专属八卦摆件）。
- **仪式卡片布局**在 `Game.jsx` ~1023-1426，是近期修复重点（按钮被挡/栏重叠都在这里）。

### 其余页面
- `Landing.jsx`：首页。`Collection.jsx`：命签册。`Agents.jsx`：智囊阁。`Community/Daily/Calendar/Dictionary`：社区/日签/日历/卦典。`Scenarios/Legal/Privacy/NotFound`。

## 2. 逻辑层 `src/game/`

| 文件 | 职责 |
|------|------|
| `useGameFlow.js` | **全流程状态机**（超大文件，20 万+ 字符）。所有 `handle*` 回调、phase 流转、仪式、SSE、降级。**改流程首选** |
| `cyberRitual.js` | 起卦/装卦/三变/两径的确定性生成：`generateQinianSeed`、`buildZhuangGuaLog`、`buildSanBian`、`buildFuTie`、`getGuaByIdx`、`GUA_64` |
| `yijing.js` | 易经卦象数据/推演 |
| `localEngine.js` | 本地兜底引擎（后端失败时用） |
| `context_assembler.js` | 拼接到 LLM 的上下文（≤480 字预算） |
| `costControl.js` | 成本控制 |
| `caseFile.js` / `constants.js` | 档案 / 常量 |

## 3. 服务层 `src/services/`

| 文件 | 职责 |
|------|------|
| `inferenceEngine.js` | **核心推理**：Agent 池构建、推荐智囊、决策树、降级（本地语义匹配兜底） |
| `apiClient.js` | 后端请求封装（超时层级：apiClient 6s < race 8s < 外层 12s） |
| `multiAgentFramework.js` | 多智囊框架 |
| `deliberationClient.js` | 辩论流式客户端 |
| `memoryStore.js` | 长期记忆（localStorage `yance_long_term_memories_v1`）、反馈、回忆 |
| `mentionProtocol.js` | 智囊相互 mention 协议 |
| `tracker.js` | 埋点 + Web Vitals |
| `auth.js` / `baseConfig.js` / `dataSync.js` / `featureFlags.js` | 认证/配置/同步/开关 |

## 4. 组件层要点

- `components/board/AgentDialogueOverlay.jsx`：**智囊/演对话浮层**。含 AgentAvatar、ensureUniqueIds、dedupeAgents、mention 高亮、工具卡片、打字机。`agent_select` 阶段在此完成智囊遴选与推荐。
- `components/board/ProcessStepper.jsx`：顶部流程条（七节点）。
- `components/board/ChoiceHud.jsx`：抉择命牌（图二候选 / 图三命签）。
- `components/fate/FateCardPanel.jsx` / `FateCard.jsx`：命牌面板（6 段结构：卦/卦辞/择路/锦囊/禁忌/回溯）。
- `components/board/LightOrb.jsx`：3D 中心光球 + 八卦阵（仪式阶段也要保证「演」字与八卦台可见）。
- `components/board/YaolinesFormation.jsx`：六爻 3D 棍状模型（**已被禁用**，返回空 group，用户要求删除）。
- `components/board/DestinyRevealFX.jsx`：浮起命牌 3D 特效（**必须返回 `<group visible={false}>`**，完全不渲染）。

## 5. 主题 `src/theme/cyberMystic.css`
- 全局赛博玄学样式：CRT 扫描线（`.cyber-crt-scanlines`）、数据雨（`.cyber-data-rain`）、金线边框、seal-text 等。
- 三层特效层都设为 `pointer-events:none` + 低透明，避免挡点击。
- 改动特效优先级：用户在意"仪式感"但**讨厌花哨/挡内容**，透明度与 pointer-events 是硬要求。

## 6. 工具 `src/utils/helpers.js`
- `sanitizeLLMText`：清理 LLM 输出里的系统标签（`<response>/<output>/<mention>…`、【】括注、未闭合标签），所有日志/总结文本必须过它。
