## 2. 前端构建与部署

```bash
cd divergence-trae
npm run build                      # 产物 dist/
npx surge dist yance-bagua.surge.sh   # 发布 Surge（会同步生成 200.html）
```

- `vite.config.js` 的 `spaFallbackPlugin` 会在构建时把 `index.html` 复制为 `200.html`，保证 SPA 子路由刷新不 404。
- **产物文件名带时间戳**（`assets/[name]-[hash]-${Date.now().slice(-6)}.js`），发布后旧缓存自动失效——部署后**让用户强刷一次（Cmd+Shift+R）**。
- Vercel 部署：`vercel.json` 需配置 `outputDirectory: dist`。

## 3. 后端部署
- 当前生产：CloudBase **HTTP Web Function**，运行时 `Nodejs20.19`、512MB、60 秒、监听端口 9000。
- CloudBase 环境：`yance-bagua-dev-d1fq4lxm0c0541be`，地域 `ap-singapore`，免费体验版。
- 可复现部署配置已纳入 `server/cloudbaserc.json`，启动入口为 `server/scf_bootstrap`；模型密钥只保存在 CloudBase 函数环境变量中，禁止写入仓库配置。
- Function URL 必须使用 SCF `CreateTrigger(Type=http)` 创建；CloudBase CLI 3.7.1 自动创建的 HTTP Service Route 会错误绑定为普通 `SCF`，出现 `FunctionType parameter is invalid`，不要把该路由当作生产入口。
- 当前环境的容器型 CloudBase Run 不可用：`CreateCloudRunEnv` 在 `ap-singapore` 返回 `UnsupportedRegion`。
- Vercel：`api/` 与 `functions/api/` 作为 Serverless Functions 入口，保留为回滚后端。
- Railway：试用到期，执行部署会返回 `Your trial has expired`，续费前不要作为恢复方案。
- 备用 Workers：`cd worker && wrangler deploy`（`wrangler.toml`，当前不启用）。

### 3.1 CloudBase 费用边界

- 套餐：免费体验版，每个计费周期 3000 资源点，当前未开启按量付费。
- 免费体验环境不能加购资源包或开启超限按量，不会在资源点耗尽后自动产生现金账单；资源可能被限流或停服。
- 云函数按调用次数、运行时长和外网出流量消耗资源点；用量统计有延迟，发布后需在“套餐用量”持续观察。

### 3.2 当前生产限制

- 健康检查显示 `dbMode: memory`：函数实例回收后，本地内存数据不会持久保存；涉及账号、会话、收藏、长期记忆的能力不能据此宣称生产级可靠。
- 模型已配置且真实 SSE 请求验证通过，但 Stage 01 Runtime、身份隔离、Evidence Gateway 和 `/sandbox` Agent 主链迁移均未部署。
- CloudBase 是新增并行后端，Vercel 未删除；切回只需恢复 `public/api-config.js` 和 Surge `_redirects` 的后端地址。

## 5. 部署后必做
1. 验证 `/health` 返回 `200` 且 `llmAvailable: true`。
2. 验证 `/api/agent/personas`、`/api/deliberation/health` 返回 `200`，CORS 预检返回 `204`。
3. 发起一次最小真实 SSE 请求，确认至少包含 `meta`、`content`、`done` 事件且不是本地模板。
4. 强刷清缓存验证 `https://yance-bagua.surge.sh/sandbox`。
5. 走一遍核心流程：输入问题 → 仪式（起念/投钱/装卦/用神/三变）→ 遴选智囊 → 辩论 → 总结 → 抉择 → 命牌。
6. 确认无 429 崩溃、无按钮被挡、无阶段栏重叠。

## 6. 构建常见坑
- `base` 必须是 `'/'`（相对路径会在子路由下 MIME type 报错，见 vite.config.js 注释）。
- three 生态必须走 `manualChunks` 合并成 `vendor-three`，否则跨 chunk 引用出错。
- 改了 `Game.jsx` / `useGameFlow.js` 这类大文件后，务必 `npm run build` 验证编译通过（dev 不报错不代表 build 没问题）。
