## 根目录

| 路径 | 作用 |
|------|------|
| `index.html` | Vite 入口 HTML |
| `index.js` | 根入口 JS（保留，非构建主入口） |
| `vite.config.js` | **关键**：`base:'/'`（绝对路径），SPA fallback 插件生成 `200.html`，产物文件名带时间戳防缓存，three 生态 manualChunks |
| `package.json` / `package-lock.json` | 前端依赖（`type:module`） |
| `tailwind.config.js` / `postcss.config.js` | 样式构建 |
| `vercel.json` / `railway.json` / `render.yaml` | 各平台部署配置 |
| `CNAME` | 域名绑定 |
| `.oxlintrc.json` | lint 配置（`npm run lint`） |
| `README.md` / `CLAUDE.md` / `GUIDE-目录结构.md` | 说明文档 |
| `DEPLOYMENT_GUIDE.md` / `DEPLOYMENT_VERCEL.md` | 部署参考 |
| `api/` | Vercel Serverless API 入口（`api/index.js`） |
| `functions/` | Vercel Serverless Functions |
| `public/` | 静态资源（favicon、manifest、`api-config.js` 等） |
