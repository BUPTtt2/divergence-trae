### 3.1 五层总结构（从上到下）

名称

包含什么

**编排层**

LangGraph 状态机

**Agent 层**

MCP 协议工具集

被 Agent 层调用；读写记忆层

第 5 层

**记忆层**

Mem0 底座 + 五层记忆

被工具层读写；被 context\_assembler 编译后注入 Agent 上下文

### 3.3 圆桌子架构（诸智阶段内部）

角色

是什么

规则

**主持**

**代码，不是 LLM**
