## 📦 分模块详细说明（后端 → 前端对应）

### 1️⃣ PLAN 阶段 — 起卦规划

后端文件 职责 对应前端表现 planner.js 核心规划器：问题分类→维度选择→工具探测→生成演的开场分析 ① "演·思考"日志条目 ② 演的分析文本(卦象风格) ③ 维度标签 → detectQuestionType() LLM分类问题类型(travel/career/city...) 决定整个推演走向，用户看不到但影响所有后续内容 → ruleBasedDimensions() 按类型选维度(如city→财务/风险/实践/反思) 决定Agent HUD上显示哪些智囊位置 → generateYanAnalysis() LLM生成演的卦象分析文本 页面顶部"演观此问..."那段文言分析 toolProbeService.js 探测外部工具(web\_search/weather/stock) 推演日志中的"🔍 找到3条结果""☀️ 北京35°C"条目 memoryService.js recall() L3命格向量检索 "召回X条记忆"日志条目 + 注入Agent上下文

### 2️⃣ WAIT 阶段 — 天机追问

后端文件 职责 对应前端表现 autonomyGate.js 判断是否需要追问用户 ClarifyDialog弹窗 — "天机不全，需再问：盘缠几何？" → detectMissingPrereqs() P0检测：缺预算/时间/目的等 追问弹窗中的问题文案 → detectToolAnomalies() P2检测：工具返回异常(如大雪/暴雨) 追问中的"天机示警" → buildQuestion() 生成赛博风追问文案 "何日启程？""盘缠几何？"

### 3️⃣ EXECUTE 阶段 — 智囊发言

后端文件 职责 对应前端表现 deliberationEngine.js 调度智囊+过滤无关Agent Agent HUD上显示哪些智囊卡片 → Agent过滤逻辑 按questionType过滤市集Agent "推荐智囊"列表（不会给租房推职场老兵了） agentEngine.js 并行调用所有Agent 每个智囊卡片依次"说话"，显示气泡内容 agentPool.js Agent定义+System Prompt 决定每个智囊说什么、不能说什么 → buildAgentSystemPrompt() 注入视角约束（风眼禁谈健康） 风眼不再说健康风险，钱谷只谈钱 → getResidentAgents() 常驻Agent(风眼/镜渊/钱谷等) 卦盘上的固定位置角色 mcpService.js Agent可调用的工具 智囊发言中引用的搜索/天气/股票数据

### 4️⃣ REFLECT 阶段 — 矛盾检测

后端文件 职责 对应前端表现 reflector.js 整合智囊观点、检测矛盾 结果页的"诸家争鸣"矛盾对比 → detectConflicts() 检测维度间立场冲突(风险vs体验) 结果页显示"风险维度凶，体验维度吉" → aggregateByPerspective() 按维度汇总 stance(吉/凶/平) 每个维度的吉凶标签

### 5️⃣ ORACLE 阶段 — 起卦

后端文件 职责 对应前端表现 reflector.js 八卦起卦(本卦→变卦→动爻) 结果页中央的卦象符号(乾/坎/离...) → generateOracleText() LLM生成卦辞(赛博算命风) "【坎卦】·二爻动。诸象偏吉..." → PERSPECTIVE\_TO\_TRIGRAM 维度→八卦映射(风险=坎,财务=兑) 卦象由哪些维度决定

### 6️⃣ COMMIT 阶段 — 记忆沉淀

后端文件 职责 对应前端表现 memoryService.js consolidate() L2摘要→L3命格写入 推演日志"X条收入命格"+下次推演的记忆召回 followUpService.js 后续提醒/行动建议 结果页的"行动建议"

## 🔄 数据流全链路（以"我要不要在北京租房"为例）

```
用户输入"我要不要在北京租房"
  ↓
Game.jsx → POST /api/deliberation/start
  ↓
deliberationEngine → PLAN
  ├─ detectQuestionType() → "city" (正则命中"租房" ✅)
  ├─ ruleBasedDimensions("city") → [财务,风险,实践,反思]
  ├─ toolProbe.detectToolNeeds("city") → ["web_search"] (无weather ✅)
  ├─ toolProbe.probe() → web_search: "🔍 找到3条结果"
  ├─ memory.recall() → 过滤低分记忆, 不召回西藏高原 ✅
  ├─ autonomyGate.evaluate() → detectMissingPrereqs: 缺预算
  ├─ generateYanAnalysis() → LLM生成卦象风格分析
  └─ state → WAIT
  ↓
SSE推送到前端:
  - thought: "演·起卦：用户问「我要不要在北京租房」"
  - state_change: PLAN→WAIT
  - thought: "演观此问，观其北京租房之事宜..." (卦象分析)
  - thought: "演·追问：1个问题"
  ↓
前端展示:
  ① 演分析文本 ✅
  ② ClarifyDialog弹窗: "天机不全，需再问：盘缠几何？" ✅
  ③ 推演日志显示工具探测结果(只有web_search,无天气) ✅
  ④ 不显示高原/西藏相关内容 ✅
```
