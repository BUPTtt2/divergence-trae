# 手机账号弹层修复设计

## 范围

只修复现有账号与登录弹层在手机浏览器中被顶部导航裁切、找不到边界、无法关闭和无法返回的问题。没有域名和邮件服务时，不加入形式化验证码，也不改变现有账号数据与管理员授权。

## 根因

`UserAvatar` 挂载在带 `backdrop-filter` 的固定顶部导航内。移动浏览器会让后代的 `position: fixed` 以该视觉容器为定位上下文，导致全屏遮罩实际只属于导航层，内容虽然溢出可见，但滚动、边界和点击区域均错误。

## 方案

- 使用 React Portal 将资料弹层和登录/注册弹层直接挂到 `document.body`。
- 打开任一弹层时锁定页面背景滚动，关闭时精确恢复原状态。
- 弹层使用 `100dvh`、安全区与单一内容滚动容器。
- 标题栏固定在弹层顶部，始终显示右上角“关闭”。
- 登录/注册层增加“返回账号”与“关闭”，支持系统返回意图、ESC 和点击遮罩。
- 保存按钮固定在弹层底部；页面与悬浮助手不能穿透抢点击。

## 验收

1. 手机从顶部头像和首页“我的账号”进入，看到完整顶边及关闭按钮。
2. 无论滚到资料中部或底部，关闭与保存按钮都可达。
3. 登录层可以关闭，也能返回资料层；再次点账号入口可正常重开。
4. 弹层滚动时首页不跟随滚动，关闭后首页恢复原滚动位置。
5. 桌面端行为不退化，匿名推演与现有注册登录不变。
