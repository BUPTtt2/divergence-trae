# 命牌礼成体验设计

## 目标

把推演结尾从“右侧长文档 + 3D 发光卡”收束为一件可收藏、可复看、可下载的决策纪念物。命牌只呈现本局真实数据，不把案卷原文整段粘贴到卡面。

## 体验结构

- 推演工作台、3D 场景和命牌各自独立。右侧工作台收起后，场景仍保留；命牌也可单独收起，并由右下角“命牌”印章再次打开。
- 最终命牌采用 3:4 竖版。底画是无文字的周易水墨意象；标题、问题、判断、行动和改路信号由 HTML 排版，避免图片模型把中文写错。
- 卡面只保留六类信息：本局编号、卦名、二至四字命题、所问摘要、选择的一条路径、三枚决策印记（判断/行动/戒线）。证据和完整过程留在展开区。
- 删除 3D 命牌、环形光圈、射线和漂浮字。最终场景只保留低亮度八卦台与水墨环境。

## 图像生成

- 默认使用项目内置水墨底画，任何情况下都能形成完整命牌。
- 配置火山方舟后，前端在命牌落印后按需调用后端；后端用 Seedream 生成一张无文字 3:4 底画，成功后替换底图，失败不阻塞收藏与下载。
- Key 只存服务端环境变量。图像 URL 可能过期，因此下载/收藏所需文字内容不依赖远端图片。

## 错误与降级

- 未配置 Seedream、429、超时或内容安全拒绝时，返回可识别的 unavailable 状态，前端继续使用本地底画。
- 不显示“预设”字样。内容来源只标记为“本局生成”或“结构化归纳”，标记不占布局主位。

## 验收

- 最终阶段没有 3D 发光命牌或周边射线。
- 命牌和工作台均可收起、再次打开，场景不会因收起消失。
- 长问题、长总结、空数组和无图像 Key 均不会破坏卡面。
- 图片接口不向浏览器暴露 Key，并且只允许会话所有者调用。
