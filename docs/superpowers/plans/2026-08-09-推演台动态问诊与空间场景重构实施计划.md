# 推演台动态问诊与空间场景重构实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复轻量问答死循环和失效 Session 重试，并交付动态批量追问、未知授权继续以及与真实运行状态联动的空间推演台。

**Architecture:** 后端以混合路由器判断是否值得建立 Session，案卷分析器每轮根据最新事实生成去重问题批次；前端以单请求门禁和失效会话恢复器消费该状态。视觉层保留旧 3D 场景资产，使用事件投影驱动签片、光路和卷轴，不再用无状态装饰环或多块浮窗表达流程。

**Tech Stack:** React、Vite、React Three Fiber、Framer Motion、Node.js、Express、Node Test Runner。

## Global Constraints

- 不把简单问题强制送进 Multi-Agent。
- 每轮最多 3 个互不重叠问题，提交整轮后才生成下一轮。
- 未知可动态增删、可单项跳过，非阻断未知不得阻塞推演。
- `SESSION_NOT_FOUND` 必须清理失效状态，不得重放同一提交。
- 恢复原视觉资产，移除收缩圆环，并保证 iPad 可完成全流程。
