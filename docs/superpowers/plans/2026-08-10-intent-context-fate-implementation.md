# 意图、按需上下文与命牌实施计划

1. 在服务端建立统一意图帧与冲突消解，接入对话路由和深度路由。
2. 把快捷选项改为结构化动作，前端展示“我理解为”与路由理由。
3. 为健康行为改变补齐专用案卷字段、信息充足度和安全说明。
4. 在 Session 计划中增加上下文档案，记录立案、回答、成员变化、智囊输出、汇总、路径和命牌；增加按需查询接口。
5. 智囊提示词只装载当前案卷、当前轮、指定参与者历史和相关证据。
6. 统一命牌服务端合同，前端适配器优先使用主总结；收藏改为云端或本地兜底并返回真实状态。
7. 将原创命牌底纹放入项目资产并接入统一命牌组件，保持顶部阶段栏现有样式。
8. 只执行生产构建，不运行测试套件；随后单向同步生产候选版，部署后端和前端并报告未验证风险。
