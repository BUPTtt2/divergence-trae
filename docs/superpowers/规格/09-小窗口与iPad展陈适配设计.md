# 09 · 小窗口与 iPad 展陈适配设计

## 1. 布局断点

- `>= 1180px`：案卷、中央阵图、智囊/实况三栏并存。
- `768px～1179px`：中央阵图保留，案卷/实况/智囊进入可切换底部抽屉；默认展开实况。
- `< 768px`：单列流程，阵图高度不超过 `40dvh`，行动区固定在安全区上方。

小窗口不能把桌面侧栏等比压缩，也不能让面板覆盖整个场景。信息面板必须有明确的收起、展开和分页状态。

## 2. 展陈要求

使用 `100dvh` 与四边 safe-area；触控目标不小于 44px；关键文本全部在 DOM；不依赖 hover；软键盘弹出后输入和主按钮仍可见；横竖屏切换不丢 Session；现场默认标准动画但可一键减弱或关闭。

## 3. 验收尺寸

至少验证 1024×768、768×1024、834×1194、1194×834、390×844，以及桌面窄窗 900×700。所有尺寸不得横向溢出，任务、当前事件和下一步按钮必须可达。
