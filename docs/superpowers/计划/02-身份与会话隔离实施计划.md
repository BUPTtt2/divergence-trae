# Stage 02 · 身份与会话隔离实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 Agent Runtime 建立不可伪造的身份、密码校验和 Session/Event/Memory/Custom Advisor 所有权隔离。

**Architecture:** 使用 Node `crypto` 实现无新增依赖的 HMAC access/refresh token 与 scrypt 密码服务；Express 在进入 Deliberation Engine 前建立 verified principal 并加载 owner Session；前端所有新轨请求携带 Bearer token，SSE 由 EventSource 改为可设置 Authorization 的 fetch stream。

**Tech Stack:** Node.js 20、Express 4、Node `crypto`、Node `node:test`、React 19、Fetch/ReadableStream、现有内存/PostgreSQL 数据层。

## 全局约束

- 严格遵循 `docs/superpowers/规格/02-Agent运行时身份与会话隔离设计.md`。
- 不修改 `Game.jsx`、`useGameFlow.js`、`components/board/**`、`theme/**` 或线上部署配置。
- 不接受 body/query/header 自报 `userId` 为 Runtime 身份。
- 生产环境不得使用默认或少于 32 字符的签名密钥。
- 不在日志、错误、事件或测试快照中输出密码、token、Authorization header。
- 每项行为先写失败测试并确认因目标漏洞失败，再写最小实现。

- [ ] **Step 1：写失败测试**

测试必须覆盖以下可观察行为：

```js
test('signed access token cannot be forged by changing sub', () => {
  const pair = issueTokenPair({ userId: 'user_a', kind: 'anonymous' }, { secret: TEST_SECRET, now: 1000 });
  const parts = pair.accessToken.split('.');
  const claims = JSON.parse(Buffer.from(parts[1], 'base64url').toString());
  parts[1] = Buffer.from(JSON.stringify({ ...claims, sub: 'user_b' })).toString('base64url');
  assert.throws(() => verifyToken(parts.join('.'), 'access', { secret: TEST_SECRET, now: 1001 }), /AUTH_REQUIRED/);
});

test('refresh token is rejected where access token is required', () => {
  const pair = issueTokenPair({ userId: 'user_a', kind: 'registered' }, { secret: TEST_SECRET, now: 1000 });
  assert.throws(() => verifyToken(pair.refreshToken, 'access', { secret: TEST_SECRET, now: 1001 }), /AUTH_REQUIRED/);
});

test('scrypt password hash never contains the plaintext and verifies only the right password', async () => {
  const encoded = await hashPassword('correct horse battery staple');
  assert.equal(encoded.includes('correct horse battery staple'), false);
  assert.equal(await verifyPassword('correct horse battery staple', encoded), true);
  assert.equal(await verifyPassword('wrong password', encoded), false);
  assert.equal(await verifyPassword('correct horse battery staple', 'legacy-plaintext'), false);
});
```

- [ ] **Step 3：实现最小 token 服务**

- [ ] **Step 4：实现最小 password 服务**

使用异步 `crypto.scrypt`、16 字节随机 salt、64 字节 key；编码为 `scrypt$16384$8$1$<salt>$<hash>`，解析时严格检查字段数量和数值，错误格式直接返回 false。
