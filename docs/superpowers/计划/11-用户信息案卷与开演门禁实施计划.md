# 11 · 用户信息案卷与开演门禁实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在任何 Agent 执行前建立、展示并由用户确认权威案卷，同时按风险控制最小必要追问。

**Architecture:** 服务端以 `plan.caseFile` 作为唯一案卷，`READY` 作为人工确认门禁；前端只渲染服务端案卷并调用确认接口。历史记忆默认待确认，多轮回答累积保存。

**Tech Stack:** Node.js、Express、React、SSE、node:test、PostgreSQL/内存双模式。

## Global Constraints

- 不展示内部思维链，只展示公开状态、理由和证据。
- 不在用户确认前采用历史记忆。
- 快推演最多 1 问，标准最多 3 问，深度最多 4 问。
- 所有新行为必须先写失败测试并观察预期失败。
- `server/.memory-db.json` 不提交。
