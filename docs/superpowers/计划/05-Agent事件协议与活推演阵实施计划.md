# 05 · Agent 事件协议与活推演阵实施计划

## 1. 收敛事件事实层

建立版本化 `AgentEventV1`、领域事件白名单和公开投影；统一 `EventBus/EventStore` 的写入责任，补齐顺序、相关性、因果与可见性字段。

## 2. 做可靠 SSE

实现按 `sequence` 补发、身份与可见性过滤、实时/重放同构；前端保存游标并对重复、旧序和乱序事件做确定性处理。

## 3. 建立前端事件投影

把事件归约为任务、智囊、证据、主张、冲突、审批和传输状态；旧 phase 只保留展示兼容，不再直接解释 Agent 行为。

## 4. 接入语义动画

中央推演阵消费事件投影，完成计划、查证、冲突、重规划、审批、结晶六类提示；动画不发业务请求，长文本和关键操作保留在 DOM。

## 5. 验证与交付

覆盖事件合同、唯一写入、游标重放、断线去重、可见性、reduced-motion 和构建；用真实 Session 做一次断线恢复验收，独立提交推送，不部署生产。
