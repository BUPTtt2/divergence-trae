# 12 · 可中断 Multi-Agent 对话实施计划

## 1. 交付范围

1. 以单一对话面替换常驻活推演阵、旧交互 Dock 与交互阶段底部导航。
2. 输入、规划、追问和案卷确认阶段不挂载 3D Board。
3. 修正 `ask_user` 的 CLARIFY 响应契约。
4. 增加 PostgreSQL `deliberation_commands`、插话接口与 ReAct 安全检查点。
5. 接通补充、纠正、追问、暂停四种用户命令及公开事件。
6. 保持结果、卦象和分岔阶段现有展示，不扩大到 Agent Studio。

## 2. 发布门禁

- 生产 `DATABASE_URL` 必须存在并执行 015 迁移。
- Vercel 后端和 Surge 前端必须来自同一提交。
- 现场人工验收：连续两轮追问、推演中补充、纠正后回案卷、暂停、1024×768 横屏输入可达。
- 本轮按产品负责人要求不由 Codex 代测；发布后由负责人按上述场景反馈，未验收前不标记生产完成。
