# 06 · 卦象认知扰动器实施计划

> **供 Agent 执行：** 必须使用 `superpowers:executing-plans`，逐项按测试先行完成。

**目标：** 将现有卦象裁决链改造成确定性、可追溯、不会修改事实与安全边界的认知 Lens，并完成 iPad 横竖屏展示。

**架构：** 服务端以独立的 64 卦目录和纯函数生成扰动计划，由 Reflector 保存并通过现有 Agent Event V1 发布；前端事件投影负责恢复 Lens 状态，DOM 卡片负责解释来源、任务、贡献和锁定边界。现有证据网关、审批流程和 Session 所有权保持不变。

**技术栈：** Node.js ESM、`node:test`、React 19、Framer Motion、CSS Media Query、Vite。

## 全局约束

- Lens 只改变审查问题，不修改事实、证据、风险、审批和用户选择。
- 同一规范化输入必须得到相同 Lens 与任务。
- 每局最多生成 3 个 Lens 任务，每个任务必须有 `causedBy`。
- 禁止输出吉凶统计、“可进”“宜止”或确定性命运判断。
- 事件沿用 `AgentEventV1 schemaVersion: 1`，历史重放不触发入场动画。
- iPad 覆盖 768×1024 竖屏和 1024×768 横屏，触控目标不小于 44×44 CSS px。
- 不执行生产部署，不提交 `server/.memory-db.json`。
