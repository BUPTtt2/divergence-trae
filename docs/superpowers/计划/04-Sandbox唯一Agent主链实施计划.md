# 04 · Sandbox 唯一 Agent 主链实施计划

## 1. 收口入口

新增 `useSandboxFlow`，默认选择 Agent Runtime，legacy 只由构建变量显式开启；用纯函数测试锁定默认值和状态映射。

## 2. 完成新轨视图适配

补齐现有 Game 展示层所需的聚合字段和交互别名。智囊、发言、总结、动态选项、命签和提交只读取 Deliberation Session，不调用旧轨生成器。

## 3. 禁止静默本地假成功

Agent Runtime 启动和重试都强制远端模式；后端不可达或响应不完整时进入可见错误态，保留问题和稳定动作 ID。

## 4. 验证交付

验证运行时选择、关键交互适配、前后端测试、构建、lint 和入口扫描；更新索引并独立提交推送，不部署生产。
