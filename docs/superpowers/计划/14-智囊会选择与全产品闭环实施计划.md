# 智囊会选择与全产品闭环实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用新 Session/Event Runtime 贯通“案卷—推荐 Council—用户选择—自动开演—智囊资产”闭环，恢复旧版有价值的用户参与，不恢复旧状态机。

**Architecture:** 后端新增版本化 `Council` 投影和真实 Advisor Catalog；Planner 只产生可解释候选，用户确认后 Council 才成为执行输入。前端在案卷和推演之间增加紧凑组队门禁，调用一个原子 `confirmCouncilAndExecute` 动作；智囊阁改用同一后端目录。

**Tech Stack:** React 18, React Router, Framer Motion, Express, PostgreSQL/内存双模式 DB adapter, Node test runner, Vite.

## Global Constraints

- 默认主链仍是 `useDeliberationFlow` + `deliberationEngine`，不恢复 `useGameFlow` 双轨。
- 用户未确认 Council 前不能执行 Agent；确认后一个操作完成持久化和开演。
- 所有 Session、Council、我的智囊和订阅路由必须验证 owner。
- 市集不再注入 localStorage 样例；无真实数据时显示空状态。
- 推荐结果必须包含本局任务、原因、覆盖变化、来源和预算。
- 动画只消费真实事件；“已选中”不得显示为“正在推演”。
- iPad 1024×768 和小窗口的关键触控区不小于 44px，组队门禁不遮挡顶部进度和底部主操作。
