# 03 · 工具与证据网关实施计划

## 1. 建立可信工具目录

为现有工具补齐执行模式、风险、证据类型、来源与 Agent 可访问性；mock 从 Agent 工具清单移除，旧静态数据明确标记不可作为当前事实。

## 2. 实现统一证据网关

完成 allowlist、风险门禁、结果判定、证据标准化、提示词注入清洗和审计事件。先用失败测试锁定 mock、静态数据、错误结果和越权工具的行为。

## 3. 切换 Agent 主调用点

ToolProbe、ReAct 和兼容 MCP 调用统一接入网关；黑板与状态保存 Evidence Envelope，不再把“函数未抛错”视作成功。

## 4. 验证与交付

运行后端全测、前端测试与构建、定向 lint 和绕过扫描；更新索引与限制说明后形成独立提交并推送。生产环境保持不变。
