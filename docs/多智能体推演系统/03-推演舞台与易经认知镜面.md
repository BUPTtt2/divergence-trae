# 03｜推演舞台与易经认知镜面

## 1. 舞台不是背景动画

舞台与 Session 事件绑定：智囊入阵、开始执行、工具查证、形成观点、失败、完成和出现冲突都会改变对应角色的状态。正在发言的智囊在场景中显示内容摘录，右侧伴行栏保留完整贡献和过程记录。

视觉遵循三层信息密度：

1. 舞台层展示“谁在做什么”；
2. 伴行栏展示“当前可操作内容”；
3. 决策案卷展示“完整依据和路径”。

三层不会同时争夺主视觉。案卷阶段使用实色阅读面板，避免背景字符穿透正文；小窗口和 iPad 使用单列滚动布局，所有关键按钮保持可见。

## 2. 易经如何进入推演

系统把六个审查视角映射为六爻，每爻只有三种知识状态：

- 已证：该视角的关键主张具备已采信依据；
- 未知：仍缺少会改变判断的信息；
- 冲突：智囊观点或证据互相矛盾，对应动爻。

卦象因此是一次认知镜面，而不是随机算命文本。用户可以看到为什么形成这一卦、六爻各自对应什么视角，以及已证/未知/冲突的数量。它只能增加审查问题，不能改变已确认事实、风险边界和用户选择。

## 3. 命牌

命牌是最终决策凭证，保存原问题、所选路径、关键行动、用户本心、卦象摘要和时间。命牌在最终页面持续显示，完整过程可从案卷恢复，不再出现前后两张内容不一致的卡片。
