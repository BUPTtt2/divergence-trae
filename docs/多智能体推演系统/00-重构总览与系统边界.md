# 00｜重构总览与系统边界

## 1. 产品定义

Sandbox 不是“把多个提示词同时发给模型”的辩论页，也不是所有输入都要经历的固定仪式。系统先自然回应并选择直接解答、轻量选择、事实查询、深度决策或安全响应；只有深度决策进入可中断、可追溯、由用户掌握最终决定权的多 Agent 决策链。

## 2. 当前主链

```mermaid
flowchart TD
    U[用户提出问题] --> I[对话接待 Agent]
    I --> J{选择执行通道}
    J -- 直接解答 --> Z[给出答案并结束]
    J -- 轻量选择 --> K[先给临时判断或行动]
    K --> N{是否存在会改变建议的未知}
    N -- 否 --> Z
    N -- 是 --> Q0[补充一个问题或一组独立问题]
    Q0 --> K
    J -- 事实查询 --> T0[调用工具并标注来源]
    T0 --> Z
    J -- 安全响应 --> S0[安全边界与替代路径]
    J -- 深度决策 --> A[案卷分析 Agent]
    A --> B{信息是否足以改变判断}
    B -- 否 --> Q[追问一个依赖问题或一组独立问题]
    Q --> A
    B -- 是 --> C[事实/理解/未知/冲突案卷]
    C --> H{用户确认案卷}
    H -- 补充或纠正 --> A
    H -- 确认 --> O[编排总管 Agent]
    O --> S[推荐智囊 + 我的智囊 + 市集智囊]
    S --> G{用户确认智囊会}
    G --> R[每位智囊独立执行]
    R --> T[需要时调用工具并记录证据状态]
    T --> V{所有已确认智囊是否完成}
    V -- 否 --> R
    V -- 失败且未豁免 --> X[暂停并允许重试/换人]
    V -- 是 --> W[本轮用户审阅]
    W -- 追问单个智囊 --> R
    W -- 补充/纠正 --> A
    W -- 确认 --> F[反思与汇总 Agent]
    F --> L[易经认知镜面：已证/未知/冲突]
    L --> P[2-3 条有差异的可执行路径]
    P --> D{用户选择}
    D --> M[命牌与完整案卷归档]
```

## 3. 能力边界

- 模型输出不是事实。用户原话、可信工具结果、模型推断分别存放。
- 易经不是预测器。六爻映射的是六个审查视角的知识状态，用于暴露未知、冲突和反转条件。
- 市场价格、政策、行情等时效信息必须经真实工具查证；搜索建议和结果数量不能作为证据。
- 标准推演必须取得每位已确认智囊的独立贡献；缺席智囊不能被其他模型的输出冒充。
- 补充和纠正会停止当前轮并重新分析案卷；不会带着错误上下文继续自动推演。

## 4. 生产级结论

当前实现已具备生产级主链的结构和可测试闭环，但仍属于复赛体验版，不应宣称为无人监管的高风险决策系统。医疗、法律、投资等场景必须增加专业数据源、免责声明和人工升级机制。

自然对话分流、模型降级和安全预算以《05｜自然对话分流与模型安全设计》为准。
