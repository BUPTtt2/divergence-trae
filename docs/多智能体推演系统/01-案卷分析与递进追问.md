# 01｜案卷分析与递进追问

## 1. 为什么不再固定三问

提问数量不是产品目标。案卷分析 Agent 每轮读取：原始问题、已回答内容、历史案卷和当前未知，再决定是否继续以及下一条最有决策价值的问题。问题可以有依赖关系，例如先确认“实习是否稳定”，再追问“能承受多少月固定租金”；后者不会提前出现。

系统允许 2—8 个动态信息字段，但每次只展示当前可回答的一组。简单即时选择可以快速进入推演；租房、转职、产品决策等问题会根据缺口继续深入。

## 2. 案卷的四类内容

1. **已确认事实**：只来自用户明确回答或已采信证据。
2. **系统理解**：Agent 对问题的结构化复述，必须与事实分栏显示。
3. **仍未知**：可能改变结论但尚未回答的变量，不因为“问过几题”就清零。
4. **冲突**：同一变量出现互相矛盾的信息，必须回到用户确认。

## 3. 记忆规则

- 本轮回答先进入会话案卷，不直接成为长期记忆。
- 召回的历史记忆默认待确认，用户选择后才可用于本轮。
- 推断不会伪装成用户画像；长期记忆应保存来源、时间、置信度和是否由用户确认。
- “暂不回答”会保留为授权未知，不阻塞低风险推演，但会降低结论确定性。

## 4. 降级行为

强模型可用时由案卷分析 Agent 生成递进问题；不可用时使用按决策领域设计的保守字段集。降级会在过程记录中可见，不会伪装成模型完成。
