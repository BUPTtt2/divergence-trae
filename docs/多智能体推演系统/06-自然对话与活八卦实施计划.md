# 自然对话与活八卦实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让简单问题即时结束、复杂问题按需进入推演，并让八卦舞台成为真实 Session 事件的空间化呈现。

**Architecture:** 服务端入口先由确定性路由和对话接待器决定 `direct / lightweight / lookup / deep / safety`，只有 `deep` 建立完整案卷。模型路由按实际 Provider 请求计量并对 429 熔断。前端把既有投影转换成稳定的舞台视图模型，3D 场景只消费该模型，侧栏只承担当前动作和可追溯详情。

**Tech Stack:** Node.js、Express、React 19、React Three Fiber、Three.js、Framer Motion、Node Test Runner。

## 全局约束

- API Key 仅存在于服务端环境变量，不进入 Git、浏览器响应或客户端日志。
- `1+1 等于几`不创建推演会话；轻量问题先给价值，再决定是否追问。
- DeepSeek 普通任务显式关闭 thinking；连续两次 429 后熔断。
- 每个可见舞台节点必须能追溯到事实、未知、智囊、工具、冲突、用户插话或结论事件。
- 桌面端不以大弹窗覆盖舞台；1024px 以下使用可收起底部抽屉。
- 支持 `prefers-reduced-motion`，关闭非必要旋转、漂浮和粒子运动。
- 不新增静态装饰 Canvas；可交互状态由代码和 Session 事件生成。
