# 02｜智囊资产编排与定向对话

## 1. 三类智囊来源

- **我的智囊**：用户在铸造台创建，形成可执行契约，不只是人物设定。
- **市集智囊**：提供城市生活、职业路径、现金流、关系沟通、学习成长、产品判断、风险审查和行动设计等常见能力。
- **系统推荐**：编排总管根据案卷中的任务、风险和视角缺口推荐，用户仍可增删。

## 2. 编排总管负责什么

编排总管不代替智囊发言。它负责拆分任务、解释推荐理由、避免重复视角、设置每位智囊的输入边界，并确认哪些智囊需要工具。用户确认阵容后，系统冻结本轮名单。

## 3. 每位智囊的交付契约

每位智囊至少输出：主张、依据、假设、置信度、反转条件和引用证据。系统必须等待所有已确认智囊完成；失败时显示失败原因，并让用户重试、更换或明确豁免。

## 4. 用户如何参与

- **补充事实**：停止本轮，交给案卷分析 Agent 重整后再次确认。
- **纠正案卷**：停止本轮，修改错误事实或理解。
- **追问智囊**：可以选择单个智囊或全体分别回答。单个追问不会重新调用其他智囊，也不会清空他们已有结论。
- **暂停推演**：保存会话状态，恢复后继续原轮。

## 5. 铸造台

铸造过程采用动态访谈：模型判断角色边界、擅长问题、证据偏好、禁区和输出形式是否已经充分。它不再以固定三题结束；生成后的标签可编辑，实际执行遵循保存的能力契约。
