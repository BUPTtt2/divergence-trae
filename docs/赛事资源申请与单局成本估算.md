# 演策赛事资源申请与单局成本估算

更新时间：2026-08-11。报价以火山引擎正式结算页与赛事实际授予模型为准。

## 推荐接入

- 对话与编排：优先豆包 Seed 2.1 Pro；若赛事只开放 `doubao-1.5-pro-32k`，直接使用该模型，不改变产品链路。
- 终局命牌文案：沿用对话模型，额外一次调用，输出上限 220 tokens。
- 终局画境：即梦 Seedream 4.5，每个完成的推演最多生成一张；失败或超时使用本地典藏底画，不阻断收藏。
- 网页搜索：只在确有外部事实核验需求时调用，不作为每局固定步骤。

## 保守预算

按每局 9–13 次文本调用、80,000 tokens、1 张即梦图片预留。80,000 tokens 用 60,000 输入、20,000 输出估算。

| 规模 | 文本额度 | 图片额度 | 建议并发 |
|---|---:|---:|---:|
| 500 位体验者 | 4,000 万 tokens | 500 张，建议申请 600 张 | 5 QPS / 20 路并发 |
| 1,000 位体验者 | 8,000 万 tokens | 1,000 张，建议申请 1,200 张 | 5 QPS / 20 路并发 |

若按 Seed 2.1 Pro 输入 ¥6/百万、输出 ¥30/百万与 Seedream 4.5 ¥0.25/张估算：

- 单局文本：`60,000 × 6 / 1,000,000 + 20,000 × 30 / 1,000,000 = ¥0.96`
- 单局图片：`¥0.25`
- 单局合计：约 `¥1.21`
- 500 局：约 `¥605`
- 1,000 局：约 `¥1,210`

极端按 80,000 tokens 全部以输出单价计算，单局文本 ¥2.40，加图片后 ¥2.65；500 局 ¥1,325，1,000 局 ¥2,650。

若赛事实际授予 `doubao-1.5-pro-32k`，按现有参考单价输入 ¥0.8/百万、输出 ¥2/百万估算，单局文本约 ¥0.088，加图片约 ¥0.338；正式答复赛事方时应以其授予资源的计费说明为准。

## 实耗统计

- 后端逐次保存供应商返回的 `prompt_tokens`、`completion_tokens`、`total_tokens`、模型、阶段、延迟、失败与重试，不保存 prompt、回复正文或密钥。
- 单局接口：`GET /api/deliberation/:sessionId/usage`。
- 命牌库选中卡片后，打开“命牌工具”即可查看本局 tokens、调用次数、失败/切换与估算费用。
- 方舟 Endpoint ID 无法映射公开模型名时，页面显示“成本待按模型单价核算”，不会把未知价格误报为 ¥0。
- 可在 Vercel 配置 `DOUBAO_INPUT_CNY_PER_MILLION` 与 `DOUBAO_OUTPUT_CNY_PER_MILLION`，切换模型时无需改前端。

## 生产环境变量

文本模型：`ARK_API_KEY`、`ARK_ENDPOINT_ID`（或 `DOUBAO_MODEL`）。

图片模型：复用 `ARK_API_KEY`，另配 `SEEDREAM_ENDPOINT_ID`（或 `SEEDREAM_MODEL`）。

所有密钥只进入 Vercel 后端；Surge 前端不得包含任何供应商密钥。
